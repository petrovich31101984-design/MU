## 🎯 Основные изменения

### 1. Создан новый компонент Stock.tsx
Компонент полностью копирует функциональность StockStorekeeper, но с синей цветовой схемой для соответствия теме приложения руководителя.

**Основные функции:**
- Просмотр остатков номенклатуры у всех активных сотрудников
- Сортировка лекарств ПКУ на первом месте
- Отображение единиц измерения на русском языке
- Подсветка строк с лекарствами ПКУ (индиго фон)
- Подсчёт итоговых сумм по сотрудникам

**Структура таблицы:**
- Номенклатура (с пометкой ПКУ)
- Единица измерения (амп., таб., фл., шт.)
- Цена за единицу
- Столбцы для каждого активного сотрудника
- Итого по номенклатуре

**Итоговая строка (footer):**
- ИТОГО по каждому сотруднику
- Общая сумма по всем сотрудникам

  const unitMap: Record<string, string> = {
    'ampoule': 'амп.',
    'tablet': 'таб.',
    'flacon': 'фл.',
    'piece': 'шт.'
  };
  return unitMap[unit] || unit;
};

// Сортировка номенклатуры: ПКУ лекарства вверху
const sortedNomenclature = [...nomenclature].sort((a, b) => {

  return 0;
});
