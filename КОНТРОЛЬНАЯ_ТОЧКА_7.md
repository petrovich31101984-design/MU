## 🎯 Функциональность раздела "Расходы"

### Карточки KPI:
1. **Общая сумма расхода за месяц** - показывает общую сумму всех расходов за месяц
2. **Листов расхода за месяц** - количество листов расхода за месяц
3. **Превышений лимита 6%** - количество листов с превышением лимита 6%

### Листы расхода:
Каждый лист расхода содержит:
- **Шапка листа:**
  - Дата создания
  - Сотрудник (Фамилия И.О.)
  - Пациент (Фамилия И.О.)
  - Дата рождения
  - Категория выезда
  - Название терапии
  - Стоимость терапии и лимит 6%
  - Итого по препаратам
  - Прогресс-бар использования лимита
  - Индикатор превышения лимита (⚠️ ЛИМИТ ПРЕВЫШЕН)

- **Таблица препаратов и материалов:**
  - Название
  - Тип (Лекарство/Расходник)
  - Количество
  - Цена за единицу
  - Сумма
  - ИТОГО

### Кнопки действий:
- **✏️ Редактировать** - открывает модальное окно для редактирования листа
- **📦 В архив** - отправляет лист в архив
- **📊 Excel** - экспорт в Excel (демо-функция)

### Модальное окно редактирования:
Позволяет редактировать:
- Дата создания
- Сотрудник
- Пациент
- Дата рождения
- Категория выезда
- Название терапии
- Стоимость терапии

## 📊 Тестовые данные

Раздел содержит 12 тестовых листов расхода:
- 10 листов с нормальным расходом (в пределах лимита 6%)
- 2 листа с превышением лимита 6% (ID 11 и 12)

Примеры превышения лимита:
- **Лист ID 11:** Стоимость терапии 5000 ₽, лимит 6% = 300 ₽, фактический расход 530 ₽
- **Лист ID 12:** Стоимость терапии 8000 ₽, лимит 6% = 480 ₽, фактический расход 690 ₽
