## 🔧 Технические детали

### Изменение в коде:

```tsx
// Было:
<button
  onClick={() => handlePrintMessage(msg)}
  className={`absolute -top-2 ${msg.fromId === 'storekeeper' ? '-left-8' : '-right-8'} opacity-0 group-hover:opacity-100 transition-opacity p-1 rounded-full bg-white border border-gray-300 hover:bg-gray-100 shadow-sm`}
  title="Распечатать сообщение"
>
  🖨️
</button>

// Стало:
{msg.fromId !== 'storekeeper' && (
  <button
    onClick={() => handlePrintMessage(msg)}
    className="absolute -top-2 -right-8 opacity-0 group-hover:opacity-100 transition-opacity p-1 rounded-full bg-white border border-gray-300 hover:bg-gray-100 shadow-sm"
    title="Распечатать сообщение"
  >
    🖨️
  </button>
)}
```

### Логика:
- Добавлено условное рендеринг: `{msg.fromId !== 'storekeeper' && (...)}`
- Кнопка печати рендерится только если сообщение отправлено не кладовщиком
- Упрощена логика позиционирования (всегда `-right-8`, так как кнопка теперь только для сообщений сотрудников)

## 📝 Примечания

### Логика изменения:
Кладовщику не нужно распечатывать собственные сообщения, так как:
- Он сам их отправляет и знает их содержание
- Печать нужна для архивирования входящей информации от сотрудников
- Это упрощает интерфейс и снижает количество лишних действий

### Результат:
- Интерфейс стал чище и логичнее
- Кнопка печати появляется только там, где она действительно нужна
- Пользовательский опыт улучшен
