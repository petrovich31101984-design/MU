## 📊 Функциональность раздела

### Группировка возвратов
Возвраты группируются по сотруднику и дате:
- Каждый лист содержит все возвраты одного сотрудника за один день
- Листы отсортированы по дате (новые сверху)

### Фильтрация
Три режима фильтрации:
1. **Все листы** - показывает все возвраты
2. **Ожидают** - показывает только неподтвержденные возвраты
3. **Скорректированные** - показывает только скорректированные возвраты

### Действия с позициями
Для каждой позиции возврата доступны:
- **Подтверждение** (✓) - подтверждает позицию
- **Редактирование** (✏️) - открывает модальное окно для изменения количества и причины

### Действия с листами
Для каждого листа возврата доступны:
- **Отправить в архив** (📦) - отправляет лист в архив (доступно только после подтверждения всех позиций)

### Модальное окно редактирования
Позволяет изменить:
- Количество возвращаемого препарата
- Причину возврата (выпадающий список)
