## 🎯 Основные изменения

### 1. Замена карточки
- **Было:** Карточка "Остатки у сотрудников" с общей стоимостью остатков
- **Стало:** Карточка "Не просмотренные листы расхода" с количеством листов, требующих проверки

### 2. Визуальные изменения
- **Цвет индикатора:** Изменён с янтарного (`bg-amber-500`) на красный (`bg-red-500`)
- **Цвет текста значения:** Изменён с янтарного (`text-amber-700`) на красный (`text-red-700`)
- **Значение:** Фиксированное число 12 (количество не просмотренных листов)
- **Подпись:** "(требуют проверки)" вместо "(общая стоимость)"

### 3. Удаление неиспользуемого кода
Удалены следующие переменные и импорты, которые больше не используются:
- `getCurrentPrice` - функция получения текущей цены номенклатуры
- `getEmployeeStock` - функция получения остатков сотрудника
- `totalEmployeeStock` - расчёт общей стоимости остатков у сотрудников

const getCurrentPrice = useStore(s => s.getCurrentPrice);
const getEmployeeStock = useStore(s => s.getEmployeeStock);

const totalEmployeeStock = activeEmployees.reduce((sum, emp) => {
  const empStock = nomenclature.reduce((empSum, nom) => {
    const stock = getEmployeeStock(emp.id, nom.id);
    return empSum + stock * getCurrentPrice(nom.id);
  }, 0);
  return sum + empStock;
}, 0);
