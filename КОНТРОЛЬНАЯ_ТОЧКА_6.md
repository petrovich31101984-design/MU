## 🔧 Технические детали

**Файл изменен:** `src/components/StockStorekeeper.tsx`

**Добавленные функции:**

```typescript
// Преобразование единиц измерения
const formatUnit = (unit: string) => {
  const unitMap: Record<string, string> = {
    'ampoule': 'амп.',
    'tablet': 'таб.',
    'flacon': 'фл.',
    'piece': 'шт.'
  };
  return unitMap[unit] || unit;
};

// Сортировка номенклатуры: ПКУ лекарства вверху
const sortedNomenclature = [...nomenclature].sort((a, b) => {
  if (a.category === 'medicine_pku' && b.category !== 'medicine_pku') return -1;
  if (a.category !== 'medicine_pku' && b.category === 'medicine_pku') return 1;
  return 0;
});
```

**Изменения в таблице:**
- Заменен `nomenclature.map` на `sortedNomenclature.map`
- Заменен `{nom.unit}` на `{formatUnit(nom.unit)}`
- Добавлено визуальное выделение для ПКУ: `className={... ${nom.category === 'medicine_pku' ? 'bg-indigo-50' : ''}}`
- Добавлен бейдж ПКУ: `<span className="ml-2 text-xs bg-indigo-100 text-indigo-700 px-2 py-0.5 rounded">ПКУ</span>`
