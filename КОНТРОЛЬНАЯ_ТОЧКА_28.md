## 🔧 Технические детали

### Функция handlePrintMessage()

```typescript
const handlePrintMessage = (msg: any) => {
  const printWindow = window.open('', '_blank');
  
  // Определяет отправителя
  const isStorekeeper = msg.fromId === 'storekeeper';
  const senderName = isStorekeeper ? 'Кладовщик' : getPartnerName(msg.fromId);
  
  // Генерирует HTML для печати одного сообщения
  printWindow.document.write(`
    <!DOCTYPE html>
    <html>
    <head>
      <title>Сообщение от ${senderName}</title>
      <style>
        /* Стили для печати */
      </style>
    </head>
    <body>
      <div class="header">
        <h1>📨 Сообщение</h1>
        <p><strong>От:</strong> ${senderName}</p>
        <p><strong>Дата отправки:</strong> ${formatDateTime(msg.date)}</p>
        <p><strong>Дата печати:</strong> ${currentDate}</p>
      </div>
      <div class="message-box">
        <div class="sender">${senderName}</div>
        <div class="message-text">${msg.text}</div>
        <div class="message-date">${formatDateTime(msg.date)}</div>
      </div>
    </body>
    </html>
  `);
  
  printWindow.document.close();
  printWindow.focus();
  
  setTimeout(() => {
    printWindow.print();
  }, 250);
};
```

### Кнопка печати в сообщении

```tsx
<div className={`flex ${msg.fromId === 'storekeeper' ? 'justify-end' : 'justify-start'} group`}>
  <div className={`max-w-[70%] rounded-xl px-4 py-2 relative`}>
    <p className="text-sm">{msg.text}</p>
    <p className="text-xs mt-1">{formatDateTime(msg.date)}</p>
    
    {/* Кнопка печати */}
    <button
      onClick={() => handlePrintMessage(msg)}
      className={`absolute -top-2 ${msg.fromId === 'storekeeper' ? '-left-8' : '-right-8'} 
                  opacity-0 group-hover:opacity-100 transition-opacity 
                  p-1 rounded-full bg-white border border-gray-300 
                  hover:bg-gray-100 shadow-sm`}
      title="Распечатать сообщение"
    >
      🖨️
    </button>
  </div>
</div>
```

## 📝 Примечания

### Как использовать:
1. Открыть раздел "Сообщения"
2. Выбрать диалог с сотрудником
3. Навести курсор на нужное сообщение
4. Нажать на появившуюся кнопку 🖨️
5. В открывшемся окне подтвердить печать

### Особенности:
- Печатается только одно выбранное сообщение
- Кнопка печати появляется только при наведении (hover)
- Для сообщений кладовщика кнопка слева, для сообщений сотрудника - справа
- Сохраняется информация об отправителе, тексте и времени отправки

### Преимущества:
- Более точечный подход к печати
- Можно распечатать только важное сообщение
- Не нужно печатать весь диалог
- Удобно для архивирования отдельных важных сообщений
