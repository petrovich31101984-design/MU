## 🎯 Основные изменения

### 1. Добавлена функция `handlePrintChat()`

Функция открывает новое окно браузера с форматированным содержимым диалога и автоматически вызывает диалог печати.

**Особенности реализации:**
- Открывает новое окно через `window.open()`
- Генерирует HTML-документ с форматированным диалогом
- Сохраняет визуальное оформление сообщений (цвета, выравнивание)
- Автоматически вызывает `window.print()` после загрузки содержимого
- Обрабатывает ошибку блокировки всплывающих окон

### 2. Добавлена кнопка "🖨️ Печать"

Кнопка размещена в шапке чата рядом с именем собеседника.

**Условия отображения:**
- Кнопка отображается только когда выбран диалог
- Кнопка отображается только если в диалоге есть сообщения
- Кнопка скрыта для пустых диалогов

**Стилизация:**
- Белый фон с серой рамкой
- Иконка принтера 🖨️
- Hover-эффект (изменение фона)
- Tooltip при наведении

### 3. Форматирование печатной версии

Печатная версия диалога включает:

**Заголовок:**
- Название диалога с эмодзи 💬
- Дата печати (текущая дата и время)
- Общее количество сообщений

**Сообщения:**
- Сохранено визуальное оформление (цвета, выравнивание)
- Сообщения кладовщика - справа, зеленый фон
- Сообщения собеседника - слева, белый фон
- Для каждого сообщения указано:
  - Имя отправителя
  - Текст сообщения
  - Дата и время отправки

**Стили для печати:**
- Оптимизированы для печати (@media print)
- Читаемый шрифт и размеры
- Правильные отступы и выравнивание

## 🔧 Технические детали

### Функция handlePrintChat()

```typescript
const handlePrintChat = () => {
  if (!selectedChat || selectedMessages.length === 0) return;

  const printWindow = window.open('', '_blank');
  if (!printWindow) {
    alert('Не удалось открыть окно печати...');
    return;
  }

  // Генерация HTML-документа
  printWindow.document.write(`
    <!DOCTYPE html>
    <html lang="ru">
    <head>
      <meta charset="UTF-8">
      <title>Диалог с ${partnerName}</title>
      <style>
        /* Стили для экрана и печати */
      </style>
    </head>
    <body>
      <!-- Заголовок и сообщения -->
    </body>
    </html>
  `);

  printWindow.document.close();
  printWindow.focus();
  
  setTimeout(() => {
    printWindow.print();
  }, 250);
};
```

### Кнопка печати в шапке чата

```tsx
<div className="p-4 border-b border-gray-200 bg-gray-50 flex items-center justify-between">
  <h3 className="font-semibold text-gray-800">{getPartnerName(selectedChat)}</h3>
  {selectedMessages.length > 0 && (

      title="Распечатать диалог"
    >
      🖨️ Печать
    </button>
  )}
</div>
```

## 📝 Примечания

### Как использовать:
1. Открыть раздел "Сообщения"
2. Выбрать диалог с сотрудником
3. Нажать кнопку "🖨️ Печать" в шапке чата
4. В открывшемся окне просмотра печати выбрать принтер или сохранить в PDF
5. Подтвердить печать

### Особенности:
- Печатается весь диалог целиком (все сообщения)
- Сохраняется визуальное оформление (цвета, выравнивание)
- Добавляется заголовок с информацией о диалоге
- Оптимизировано для печати на бумаге формата A4

### Обработка ошибок:
- Если браузер блокирует всплывающие окна, показывается предупреждение
- Пользователь должен разрешить всплывающие окна для сайта
