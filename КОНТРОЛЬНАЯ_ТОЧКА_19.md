## 🎯 Основные изменения

### Реализована функция sticky для столбца "Номенклатура"

При горизонтальной прокрутке таблицы столбец "Номенклатура" остаётся видимым, что улучшает удобство работы с таблицей, когда у компании много сотрудников.

---

## 🔧 Технические детали

### Изменения в thead (заголовок таблицы):

```typescript
// Было:
<th className="px-4 py-3 font-medium text-gray-600">Номенклатура</th>

// Стало:
<th className="px-4 py-3 font-medium text-gray-600 sticky left-0 bg-gray-50 z-10">Номенклатура</th>
```

**Добавленные классы:**
- `sticky` - делает элемент прилипающим
- `left-0` - позиционирует элемент слева
- `bg-gray-50` - добавляет фон, чтобы текст не просвечивал через другие столбцы
- `z-10` - устанавливает z-index, чтобы столбец был поверх других элементов

### Изменения в tbody (строки данных):

```typescript
// Было:
<td className="px-4 py-3 font-medium text-gray-800">
  {nom.name}
  {nom.category === 'medicine_pku' && (
    <span className="ml-2 text-xs bg-indigo-100 text-indigo-700 px-2 py-0.5 rounded">ПКУ</span>
  )}
</td>

// Стало:
<td className={`px-4 py-3 font-medium text-gray-800 sticky left-0 z-10 ${nom.category === 'medicine_pku' ? 'bg-indigo-50' : 'bg-white'}`}>
  {nom.name}
  {nom.category === 'medicine_pku' && (
    <span className="ml-2 text-xs bg-indigo-100 text-indigo-700 px-2 py-0.5 rounded">ПКУ</span>
  )}
</td>
```

**Добавленные классы:**
- `sticky` - делает ячейку прилипающей
- `left-0` - позиционирует ячейку слева
- `z-10` - устанавливает z-index
- Условный фон: `bg-indigo-50` для лекарств ПКУ, `bg-white` для остальных препаратов
