## 🎯 Основные изменения

### Добавлен класс `whitespace-nowrap` ко всем ячейкам таблицы

Чтобы все значения в столбцах помещались без переносов, добавлен класс `whitespace-nowrap` к:
- Заголовкам таблицы (thead)
- Ячейкам данных (tbody)
- Итоговым ячейкам (tfoot)

## 📊 Структура таблицы

### До изменений:
Текст в ячейках мог переноситься на новую строку, если содержимое было слишком длинным.

```
┌─────────────────────┐
│ Номенклатура        │
│ (может переносить-  │
│  ся на несколько    │
│  строк)             │
└─────────────────────┘
```

### После изменений:
Весь текст в ячейках отображается в одну строку без переносов.

```
┌─────────────────────────────────────┐
│ Номенклатура (всё в одну строку)    │
└─────────────────────────────────────┘
```

## 📝 Что делает класс `whitespace-nowrap`

Класс `whitespace-nowrap` в Tailwind CSS устанавливает CSS-свойство `white-space: nowrap`, которое:
- Запрещает перенос текста на новую строку
- Заставляет весь текст отображаться в одну строку
- Если текст слишком длинный, он будет выходить за пределы ячейки (но таблица имеет `overflow-x-auto`, поэтому появится горизонтальная прокрутка)
