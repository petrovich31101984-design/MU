## 📊 Функциональность раздела

### Создание диалогов
- Кнопка "➕ Новый чат" открывает список доступных собеседников
- Можно создать диалог с руководителем или любым сотрудником
- Поиск по имени собеседника

### Отправка сообщений
- Ввод сообщения в текстовое поле
- Отправка по кнопке "Отправить" или клавише Enter
- Автоматическая очистка поля ввода после отправки

### Получение сообщений
- Сообщения отображаются в чате в хронологическом порядке
- Сообщения пользователя отображаются справа (зеленые)
- Сообщения собеседника отображаются слева (белые)
- Отображается время отправки каждого сообщения

### Пометка прочитанных сообщений
- При открытии чата все непрочитанные сообщения от собеседника автоматически помечаются как прочитанные
- Счетчик непрочитанных сообщений обновляется в реальном времени

### Поиск по диалогам
- Поиск по имени собеседника
- Фильтрация списка диалогов в реальном времени

### Отображение последнего сообщения
- В списке диалогов отображается последнее сообщение
- Если последнее сообщение от пользователя, добавляется префикс "Вы: "

### useEffect для пометки прочитанных
```typescript
useEffect(() => {
  if (selectedChat) {
    const unreadMessages = messages.filter(
      m => m.fromId === selectedChat && m.toId === 'storekeeper' && !m.read
    );
    unreadMessages.forEach(msg => {
      markMessageRead(msg.id);
    });
  }
}, [selectedChat, messages, markMessageRead]);
```
